# NAK Quiz AI

> AI-powered quiz assistant for Android — by **Nadir Ali Khan** | [Team NAK](https://teamnak.com)

## What it does

NAK Quiz AI runs in the background and helps you answer quiz questions instantly. Tap the floating **⚡** button and the AI reads your screen and gives you the correct answer.

## Features

- **Floating trigger button** — tap when you see a question
- **Screen reader** — reads all text visible on screen via Accessibility Service
- **AI-powered answers** — powered by Llama 3.3 70B (Groq)
- **Screenshot protected** — overlay hidden from screen recorders
- **Supports all question types:**
  - Fill in the blank
  - Sentence alignment
  - Reading comprehension

## Tech Stack

- **Language:** Kotlin (Native Android)
- **AI Model:** Llama 3.3 70B via Groq API (free)
- **Min SDK:** Android 8.0 (API 26)
- **Permissions:** Accessibility Service, Overlay

## Setup

1. Clone the repo and open in Android Studio
2. Build APK: `Build → Build APK(s)`
3. Install on Android device
4. Open the app and grant:
   - Overlay permission
   - Accessibility service
5. Tap **⚡** on any quiz screen
