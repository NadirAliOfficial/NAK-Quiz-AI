# NAK Quiz AI

AI-powered quiz assistant for Android — generates quiz questions, grades answers, and tracks learning progress.

## Features
- AI-generated questions by topic
- Multiple choice and open-ended modes
- Score tracking and analytics
- Offline capable

## Tech Stack
- Kotlin, Android Jetpack Compose
- Local AI inference

## Build
Open in Android Studio. Requires API level 26+.
