# NAK Quiz AI

AI-powered quiz assistant for Android — generates quiz questions, grades answers, and tracks learning progress.

## Features
- AI-generated questions by topic
- Multiple choice and open-ended modes
- Score tracking and analytics
- Offline capable

## Tech Stack
- Kotlin, Android Jetpack Compose
- Local AI inference

## Build
Open in Android Studio. Requires API level 26+.

## Usage
1. Clone the repository and open the project in Android Studio.
2. Sync Gradle and let it download dependencies.
3. Connect an Android device or start an emulator.
4. Click the **Run** button (or press Shift+F10) to build and install the app.
5. Launch the app on the device to start using the quiz assistant.
